# Kidney Transplant Risk Assessment

Full-stack application for kidney transplant risk prediction and assessment.

## 📁 Project Structure
- \kidney-backend/\ → Backend API
- \kidney-frontend/\ → Frontend UI

## 🚀 Getting Started

### Backend
\\\ash
cd kidney-backend
npm install          # or pip install -r requirements.txt
npm start            # or python main.py
\\\

### Frontend
\\\ash
cd kidney-frontend
npm install
npm run dev
\\\
